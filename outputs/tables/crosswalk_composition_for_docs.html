Composition of the NSU harmonization crosswalk

Unit of observation. One row is one raw NSU spelling (pull_nsu_unit) recorded in one cell, where a cell is province × municipality × item. A spelling used in twelve municipalities is therefore twelve rows. Source: master_nsu_rename, the crosswalk built by 01_build_crosswalk.py and read by 03_clean_ms.do.

Table 2. What each category means

TermDefinition
MS & PriceThe spelling was weighed in the market survey and appears in the price file for that cell.
Price OnlyThe spelling appears in the price file for that cell but was never weighed there.
harmonizableThe same physical object is already present in that cell under a different spelling, so the gap is apparent rather than real.
empty/uncommonA genuine unit, but that cell holds no weighing of it. This is a real coverage gap.
nonsensical (recoverable)Not a unit as written — a quantity-prefixed string — but a base unit can be extracted from it.
nonsensical (unmappable)Not a unit, and no base unit can be recovered.
